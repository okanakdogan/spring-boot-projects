# 🚀 Spring Boot Projects

Welcome to my **Spring Boot Projects** repository!  
This repo is a collection of backend systems I’m building as I learn and explore modern backend development practices using **Java Spring Boot**.

> 🧠 I'm learning by doing — implementing simple or approximate versions of real-world system design techniques used by big tech companies.

Each subfolder contains a focused project that demonstrates a specific concept, architecture, or technology integration.


---

## 📚 Table of Contents

| Project | Description |
|--------|-------------|
| [usercheck](./usercheck) | ⚡ Demonstrates how tech giants check username availability at scale using Bloom Filters, Redis Caching, and Database lookups. Inspired by [ByteMonk's video](https://www.youtube.com/watch?v=_l5Q5kKHtR8). |
| *More coming soon...* | Projects like rate limiting, authentication systems, microservices with Kafka, etc. will be added here over time. |
